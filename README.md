# EMPLOYEE DATA CLEANING (PANDAS)

# OVERVIEW->

This is a simple Python project that demonstrates how to clean and preprocess a messy employee dataset using Pandas and NumPy. The project focuses on handling real-world data issues and transforming raw data into a clean, usable format for analysis.

# DATASET->

FILE: messy_employee_dataset_1000_rows.csv The dataset includes common real-world data problems such as: Missing values Invalid age entries Inconsistent date formats Duplicate records Inconsistent city name spellings

# WHAT THIS PROJECT DOES->

Handles missing and invalid values Converts age column to numeric and corrects invalid ranges Cleans and converts join_date column to proper datetime format Extracts joining_year from join_date Standardizes and normalizes city names Detects and removes duplicate records

# TOOLS->

Python Pandas NumPy

# HOW TO RUN->

1.Open the Jupyter Notebook file 2.Update the dataset file path if required 3.Run all cells step by step
